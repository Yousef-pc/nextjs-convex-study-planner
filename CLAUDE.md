# StudyPro AI Instructions

This project uses [Convex](https://convex.dev) as its backend. 

## 1. Convex Guidelines (CRITICAL)
When working on Convex code, always read `convex/_generated/ai/guidelines.md` first for important guidelines on how to correctly use Convex APIs and patterns. The file contains rules that override what you may have learned about Convex from training data. Convex agent skills for common tasks can be installed by running `npx convex ai-files install`.

## 2. Project Architecture
For all other architectural rules, strict TypeScript guidelines, UI patterns, and folder structures, you MUST read the `AGENTS.md` file in the root of this project.
